# Auxílio-Acidente LP

Landing page institucional criada para o escritório Maragonesa Silveira Advocacia, com foco em captar leads para atendimento sobre auxílio-acidente do INSS.

## Objetivo

A página tem como finalidade apresentar de forma clara e persuasiva:

- quando o segurado pode ter direito ao auxílio-acidente;
- quais tipos de acidente e sequela podem gerar benefício;
- como funciona a análise previdenciária;
- como o cliente pode entrar em contato rapidamente pelo WhatsApp.

## Visão geral

A estrutura é uma landing page de página única (one-page), com foco em conversão e comunicação direta. O conteúdo foi organizado em blocos estratégicos para conduzir o visitante da atenção ao contato final.

### Seções principais

- Hero com proposta de valor e CTA principal
- Vídeo explicativo sobre o benefício
- Explicação sobre quem pode ter direito
- Tipos de acidente e cenários elegíveis
- Informações sobre compatibilidade com o trabalho
- FAQ com dúvidas frequentes
- CTA final com incentivo ao contato pelo WhatsApp
- Rodapé institucional

## Tecnologias

- HTML5 semântico
- CSS3 com variáveis, layout responsivo e responsividade para desktop e mobile
- JavaScript vanilla para interações leves
- Imagens e ícones otimizados para web
- Google Fonts para tipografia institucional
- Schema.org para SEO e rich snippets
- Tags de tracking e campanhas com Google Tag Manager / marketing tags

## Executando localmente

Como este é um projeto estático, não há dependências de build nem instalação de pacotes.

### Opção 1
Abra o arquivo `index.html` diretamente no navegador.

### Opção 2
Servindo localmente via terminal:

```bash
python3 -m http.server 8000
```

Depois acesse:

```text
http://localhost:8000
```

## Recursos da landing

- Botão de WhatsApp fixo e CTA de conversão
- Vídeo com capa e botão de reprodução
- FAQ em accordion
- Layout adaptado para desktop, tablet e mobile
- Estrutura otimizada para campanhas de tráfego pago
- SEO básico com meta tags, Open Graph e canonical URL

## Personalização antes do deploy

Antes de publicar em produção, revise os seguintes itens:

- número de WhatsApp
- URL do domínio final
- canonical e Open Graph
- logo e imagem de compartilhamento
- texto final e mensagens de conversão
- tags de rastreamento do Google Ads / Analytics / Tag Manager

## Observações

Este projeto foi pensado como uma landing page de conversão rápida e direta, com foco em captar clientes interessados em benefícios previdenciários. A manutenção principal é feita no HTML e no CSS, com o código estruturado para facilitar ajustes simples no texto, no layout e nas campanhas.
